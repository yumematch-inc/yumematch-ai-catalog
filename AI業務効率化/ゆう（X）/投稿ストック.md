34歳サラリーマン。

## 固定ツイート（自己紹介スレッド）

```
はじめまして。ゆうです🧵

34歳サラリーマンが「時短ツール実験アカウント」を始めます。

なぜやるか、何をするか、まとめます。

1/6
```

```
【なぜ始めたか】

毎日残業2時間。
休日も仕事のこと考えてる。
このまま40代になりたくない。

「時間を作る」ことを本気で研究しようと決めた。

2/6
```

```
【何をするか】

毎週1つ、AIや時短ツールを実際に使う。
結果を正直に報告する。

うまくいったことだけじゃなく、
失敗したことも、時間を溶かしたことも全部書く。

3/6
```

```
【なぜ「正直に」書くか】

「〇〇で月収100万！」みたいな情報に疲れた。

実際に試した人の、リアルな感想が知りたい。
だから自分がそれをやる。

4/6
```

```
【目標】

1年後、仕事の時間を週10時間削減する。

その記録を全部公開します。
一緒に実験してくれる人、フォローお願いします。

5/6
```

```
というわけで、今週の実験は…

【Claude AIで議事録作成】を試します。

毎日の会議メモをAIに投げたら
どれくらい時短になるか、1週間計測します。

結果は来週金曜に報告します🔬

6/6
```

## 1週目 投稿7本

### Day 1（月）｜実験スタート宣言

```
【今週の実験】

Claude AIで議事録を自動生成する

会議終わりにスマホで録音→AIに投げる
どれくらい時短になるか1週間計測します

今の議事録作成時間：平均45分/回
目標：10分以内

結果は金曜に報告します🔬

#時短実験 #AI活用
```

---

### Day 2（火）｜気づき・思考系

```
時短って、作業を速くすることじゃないと気づいた

「やらないことを決める」が本質

昨日の会議、実は出なくてよかったやつだった
AIで議事録もらって確認したら5分で済んだ

出席してたら1時間溶けてた

#時短実験
```

---

### Day 3（水）｜実験途中経過

```
【Claude議事録実験 中間報告】

3日やってみてわかったこと

✅ 録音→文字起こし→要点整理まで全自動
✅ 1回あたり45分→8分になった
❌ 専門用語が誤変換されることがある
❌ 音声が悪いと精度が落ちる

まだ課題はあるけど、体感的には革命的

#時短実験 #AI活用
```

---

### Day 4（木）｜失敗談

```
やらかした話をします

今日AIが生成した議事録をそのままチームに送った

「小池さんが言ってた」って書いてあった
俺の名前じゃない

誤変換してたのに確認してなかった

確認の時間を削ると別のとこで時間取られる
あたりまえだけど痛感した

#時短実験 失敗談
```

---

### Day 5（金）｜結果まとめスレッド

```
【Claude AI議事録実験】1週間の結果まとめ🧵

結論から言います。

「使える。でも過信は禁物」

詳しくまとめます。

1/5
```

```
【時短効果】

議事録作成時間
Before：平均45分/回
After：平均9分/回

週5回の会議があるので
週36分 → 45分の節約

月換算で約3時間浮いた

2/5
```

```
【よかった点】

・会議中メモを取らなくていい
・会議に集中できるようになった
・要点の抜け漏れがなくなった
・後から検索できる

3/5
```

```
【ダメだった点】

・音声品質に左右される
・専門用語の誤変換がある
・確認作業が必要（ここをサボると事故る）
・オンライン会議の方が精度が高い

4/5
```

```
【総評】8点/10点

時短効果は本物。
でも「確認する」習慣とセットで使うこと。

来週は別のツールを試します。
何を試してほしいかリプで教えてください👇

5/5
```
