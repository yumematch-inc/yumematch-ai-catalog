## 設計思想

### ターゲット
- 20〜30代のサラリーマン・個人事業主・副業中の人
- AIに興味はあるが「何をどう使えばいいかわからない」状態
- 時間が足りないと感じていて、なんとかしたいと思っている
- X（Twitter）経由で流入するのでほぼスマホ閲覧

### 心理フロー（これが最重要）
このLPは「情報を伝える」のではなく、以下の感情の変化を起こす構成になっている。

```
共感（自分のことだ）
  ↓
気づき（だからか、使えないのは自分のせいじゃなかった）
  ↓
信頼（この人なら安心して任せられそう）
  ↓
行動（診断だけならやってみよう）
```

### このLPがやること
1. 「あ、自分のことだ」と思わせる（お悩みセクション）
2. 「使えないのは難しいからじゃない」という気づきを与える（インサイトセクション）
3. 「難しくなさそう・押し付けがましくない」と感じさせる（About・Why Us）
4. 「診断だけならやってみよう」と動かす（CTA）

### 競合との差別化軸
| 比較相手 | 違い |
|---|---|
| AIスクール | 学ぶ場所ではなく「設計する」場所 |
| コンサル会社 | 法人向け大規模ではなく個人・個人事業主向け |
| YouTube・SNSのハウツー | 汎用情報ではなく「あなたの業務専用」 |

## デザイン仕様

### カラーパレット
```
--navy:   #0d1040  ← メインカラー（ヘッダー・ダークセクション背景）
--navy2:  #1a1f5e  ← ナビ下トラストバー背景
--teal:   #00c4d4  ← アクセントカラー（ラベル・強調・ステップ線）
--orange: #ff5a1f  ← CTAボタン・重要ハイライト
--green:  #06c755  ← LINEボタン専用
--off:    #f7f8ff  ← セクション背景（白とネイビーの間）
--muted:  #7a7a9a  ← サブテキスト・注釈
--border: #e5e7f5  ← カードの枠線
```

### フォント
- 日本語：-apple-system, BlinkMacSystemFont, 'Hiragino Sans', 'Yu Gothic UI'
- 外部フォント読み込みなし（表示速度優先）

### ボタンスタイル
- CTAメイン：オレンジ背景・白文字・丸角・影あり
- LINE登録：グリーン背景・白文字
- ナビCTA：オレンジ・小さめ

### デザイン方針
- 余白を多く取る（詰め込まない）
- AIっぽいロボット・機械のイメージは使わない
- モバイルファースト（900px以下でレスポンシブ）
- CTAボタンはスクロール量に対して適切な頻度で配置（中段にも1つ）

### 【6】選ばれる3つの理由（差別化）

**見出し：** AIスクールでも、コンサルでもないAI時短設計室が選ばれる理由

**3カラム（各カラム上部にカラーライン）：**

```
REASON 01（teal）
🧭 「学ぶ」ではなく「設計する」
AIスクールは知識を学ぶ場所。当サービスは、あなたの仕事に合った使い方を一緒に設計する場所。
授業を受けるのではなく、今日から使える方法を即日で手に入れられる。
→ 他社比較：AIスクールは「学習」。当サービスは「設計＋実装」。

REASON 02（orange）
👤 あなたの業務専用。汎用ノウハウは提供しない
「○○業界にはこのAIが使える」という汎用情報なら、調べれば出てくる。
あなたの日常業務の具体的な内容を聞いて、その業務に絞った提案をする。
→ 他社比較：一般的な情報提供 vs 個別業務の最適化。

REASON 03（purple）
🚀 「わかった」で終わらせない伴走型
相談後に「わかった。でも結局使えなかった」が一番もったいない。
導入・設定・プロンプト設計まで一緒にやる。
→ 他社比較：アドバイスのみ vs 使えるまでサポート。
```
